# VDS_CLI_Project — Программа управления файлами и папками
Homework for Python courses FPMI (CLI project)

Программа предоставляет набор команд для создания, удаления, копирования, анализа файловой структуры и работы с файлами и папками.


## Установка

1. Клонируйте репозиторий или скопируйте файл `main.py`, `cli_interface.py`, `file_mamager.py`, `unittests.py` в свой проект.
2. Убедитесь, что у вас установлен Python 3.8+

---

## Запуск из консоли

python3 main.py <команда> [опции]

Все параметры и команды передаются напрямую через аргументы командной строки. После выполнения выбранной команды приложение завершает работу.

## Доступные команды и примеры использования


------------------------
### 1. Создание случайной файловой структуры — `create-tree`

  Создаёт случайное дерево папок и файлов в указанной директории.

  python3 main.py create-tree [path] [--max_depth N] [--max_folders N] [--max_files N]

  - `path` — путь к директории, где создать структуру (по умолчанию `Random_folders/`).
  - `--max_depth` — максимальная глубина вложенности папок (по умолчанию 3).
  - `--max_folders` — максимальное количество папок в одной директории (по умолчанию 3).
  - `--max_files` — максимальное количество файлов в одной директории (по умолчанию 4).

  **Пример:**

  python main.py create-tree Random_folders/ --max_depth 4 --max_folders 5 --max_files 6


------------------------
### 2. Удаление случайной файловой структуры — `delete-tree`

  Удаляет папку с её содержимым по указанному пути.

  python main.py delete-tree [path]

  - `path` — путь к удаляемой директории (обычно та же, где создано дерево, по умолчанию `Random_folders/`).

  **Пример:**   
  
  python main.py delete-tree Random_folders/


------------------------
### 3. Копирование файла или папки — `copy`

  Копирует файл или папку из `src_path` в `dest_path`.

  python main.py copy <src_path> <dest_path>

  - `src_path` — путь к копируемому файлу или папке
  - `dest_path` — путь к месту назначения
    
  **Пример:**

  python main.py copy ./Random_folders/source.txt ./Random_folders/backup/source_backup.txt


------------------------
### 4. Удаление файла или папки — `delete`

  Удаляет указанный файл или папку (рекурсивно).

  python main.py delete <path>

  - `path` — путь к удаляемой директории или файлу.

  **Пример:**

  python main.py delete ./Random_folders/old_folder/


------------------------
### 5. Подсчёт количества файлов — `count`

  Подсчитывает количество файлов в указанной папке и её подпапках.

  python main.py count <path>

  - `path` — путь к директории

  **Пример:**

  python main.py count ./Random_folders/



------------------------
### 6. Поиск файлов по имени — `find`

  Ищет файлы по регулярному выражению в имени.

  python main.py find <path> <pattern>

  - `path` — путь к директории для поиска
  - `pattern` — регулярное выражение для поиска.

  **Пример:**

  python main.py find ./Random_folders/ ".*.txt$"


------------------------
### 7. Добавление даты создания к имени файла — `date`

  Добавляет дату создания файла в название файла. Если указывать папку, обработка происходит для файлов внутри неё.

  python main.py date <path> [--recursive]

  - `path` — путь к директории для добавления дат файлам
  - `--recursive` — обрабатывать также все вложенные папки.

  **Пример:**

  python main.py date ./Random_folders/ --recursive



------------------------
### 8. Анализ папки — `structure`

  Выводит информацию о размере файлов и подпапок в указанной папке (верхний уровень) и общий размер.

  python main.py structure [path]
  
   - `path` — путь к директории для добавления дат файлам

  **Пример:**

  python main.py structure ./Random_folders/


------------------------
### 9. Вывод справки — `help`

  Отображает справочную информацию по всем командам.

  python main.py manual [--less]
  
  - `--less` — отображение справочной информации в уменьшенном объеме.

  **Пример:**

  python main.py manual --less

  
------------------------
### 10. Открыть интерфейс (CLI-меню) — `interface`

  Запускает интерактивное меню с выбором команд.

  python main.py interface



------------------------
## Примечания

- Все пути можно указывать как абсолютные, так и относительные.
- Если параметр `path` не указан, в некоторых командах (create-tree, delete-tree) используется директория `Random_folders/` в текущей рабочей директории.
- Для регулярных выражений используйте стандартный синтаксис Python `re`.
